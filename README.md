# Databricks Lakeflow Designer + AI Functions Demo

This repository contains a hands-on learning/demo project exploring **Databricks Lakeflow Designer**, **AI Functions**, and **No-Code / Low-Code Data Engineering workflows**.

## Project Overview

In this project, I explored how to build a visual data pipeline in **Databricks Lakeflow Designer** without writing complex PySpark code.

Using drag-and-drop operators and AI-powered features, I created an end-to-end workflow involving multiple datasets and transformations.

---

## Tools & Technologies Used

- Databricks Lakeflow Designer
- Databricks AI Functions
- Genie Code
- Databricks SQL
- No-Code / Low-Code Data Engineering

---

## Workflow Steps

### 1. Data Loading

Worked with multiple datasets:

- Orders
- Order Items
- Customers
- Shipments
- Reviews

---

### 2. Data Transformation

Applied visual operators such as:

✔ Join

✔ Aggregate

✔ Sort

✔ Output

---

### 3. AI-Powered Sentiment Analysis

Used Databricks AI Function:

```sql
ai_analyze_sentiment()
```

to analyze customer reviews.

Generated sentiment labels like:

- Positive
- Negative
- Neutral
- Mixed

---

## Traditional vs Modern Approach

### Traditional Sentiment Analysis

Usually requires:

- NLP concepts
- Machine Learning models
- Data Science algorithms
- Model training
- Python coding

### Databricks AI Function Approach

Databricks provides **prebuilt AI models/functions internally**.

So instead of building and training models manually, developers can perform sentiment analysis with **little or no code**.
